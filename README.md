# Data-driven textile art
## Project Vision
### The art piece will consist of a translucent beaded surface, backlit with an e-textile. The light will emanate from RGB LEDs that change in hue and intensity in response to weather data. The LEDs will be controlled by ESP32 for pulse width modulation.
